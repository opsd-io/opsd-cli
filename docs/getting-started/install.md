# Install

Use this page to choose how you want to start with OPSd CLI.

- For release bundles and `asdf`, see [Release Packaging](../release/packaging.md)
- For local development and manual testing, see [Development Setup](./development-setup.md)
- For the canonical configuration workflow, see [Setup](./setup.md)
- For the shortest supported path from install to render, see [Quickstart](./quickstart.md)

## Verify The Install

After installation, confirm the CLI runs and shell completion is available:

```bash
opsd version
opsd completion bash
opsd completion zsh
opsd completion fish
```
