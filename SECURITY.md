# Security

If you believe you found a security issue in OPSd, do not open a public issue.

## Report Privately

Send the report to `support@opsd.io` and mark it clearly as security-related in
the subject or first line of the message.

If the issue involves privacy or personal-data handling on the OPSd website,
you can also use `privacy@opsd.io` for the website-side concern.

## What To Include

Provide as much context as you safely can:

- OPSd version
- affected command or workflow
- impact
- reproduction steps
- logs, stack traces, or screenshots
- whether secrets, tokens, or customer data might be exposed

## Safety Notes

- rotate or revoke exposed credentials as soon as possible
- avoid including live secrets in public reports
- if a workaround exists, include it so we can judge urgency

We aim to acknowledge serious reports within two business days.
